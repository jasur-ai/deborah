# Fame / Uniqueness Test (S39.08)

> Brand elementlari **nomsiz** (logo text holda) ko'rsatiladi.
> Name-hidden fame + uniqueness.
>
> CSV: `results/raw/fame.csv`
> Columns: `participant_id,variant,element,recognized,uniqueness,association`
> (element: `evidence_mark` | `signal_rail` | `response_mosaic` | `palette` | `three_view`)

## Procedure
1. Elementni 2 soniya ko'rsatish
2. **Recognized** (binary): “Buni ilgari ko'rganmisiz?” — keyin qaysi produkttaga
   tegishli ekanini so'rash (Name recall: `Edikit` deyish)
3. **Uniqueness** (1–7): “Bu boshqa ta'lim/platforma logotiplaridan qanchalik farqlanadi?”
4. **Association** (open): “Bu sizga nimani eslatadi?” → thematic coding

## Elementlar
| Element | Tavsif |
|---------|--------|
| Evidence Mark | Rail + 3 tick + node (cobalt) |
| Signal Rail | Question'lar signal izi (left rail) |
| Response Mosaic | Mosaic javob grid (director view) |
| Palette | Cobalt + ink + paper kombinatsiya |
| Three-view frame | Director/participant/projector strukturasi |

## Target (S39.08)
- **Name recall ≥ 60%** (evidence_mark uchun)
- Uniqueness ≥ 5.0/7
- Association: ta'lim/nazorat/tekshirish temalari ≥ 60% ishtirokchida

## Tahlil
- recall %, uniqueness mean, association theme frequency
- Theme coding: 2 mustaqil coder + inter-rater agreement (Cohen's κ ≥ 0.7)
