## 2. HAR KATEGORIYA LIDERI — dizayn saboqlari (Edikit uchun)

### 2.1. Google (#1) — minimalizm apogeyi
- Sahifa: logo + qidiruv + 2 tugma. **Bitta vazifa, nol dekor**
- Saboq: "task-led interface" — foydalanuvchi bir narsa qilishi kerak bo'lgan joyda, hamma narsa olib tashlanadi
- Edikit: login sahifasi, qidiruv, test yechish — xuddi shu tamoyil

### 2.2. ChatGPT (#5) — AI chat UX
- Interfeys: minimal input + chat; **konversatsiya asosiy**
- Saboq: AI'ni UI'da ko'rsatish — oddiy, "chatbud" pattern (converge.ai: "Chatbuds — context-aware assistants")
- Edikit: AI co-pilot (research_ui_tech_deep 4.3) — "kurs bo'yicha yordam" chat, AI generator

### 2.3. Wikipedia (#11) — content-first, trust
- Hech qanday dekor; **content is the design**; konsistensiya 20 yil
- Saboq: ishonch = barqarorlik + tekshiriladigan tarkib + manbalar (digital.gov trust bilan mos)
- Edikit: portfolio/transkript — dalil-based, server-authoritative

### 2.4. Amazon (#16) — e-commerce density
- **Yuqori information density** + F/Z pattern + buyurtma oqimi
- Saboq: teacher workspace uchun — density professional bo'lishi mumkin, lekin buyurtma (task) oqimi aniq

### 2.5. BBC (#45) — editorial grid
- Qat'iy grid, tipografik ierarxiya, sokin ranglar
- Saboq: "official editorial" — landing/statistika uchun benchmark

### 2.6. GitHub (#48) — developer official
- To'q/light dual theme, qat'iy tipografika, hech qanday "fun"
- Saboq: professional platforma qanday ko'rinadi — **GitHub Primer design system** (tokenlar, dual theme) — Edikit style tizimi uchun benchmark

### 2.7. Canvas/Instructure (#69) — EDUCATION BENCHMARK (eng muhim!)

**Nega Canvas LMS UX standarti (teachfloor, checkthat, ibl.ai, dynamicpixel, g2, pcmag):**
- **87% review'lar UI'ni maqtaydi**; Capterra 4.6/5; **~41% AQSH oliy ta'lim bozori**, barcha 10 Ivy League
- **Canvas Dashboard**: kurslar **card'lar**da; Global Navigation (left sidebar) — hamma joyda bir xil
- **Sidebar**: "Coming Up" feed + "To Do" list + "Review Grades" — talaba/o'qituvchi uchun glanceable
- **SpeedGrader**: brauzerda annotatsiya, rubrik, inline feedback — **grading UX standarti** (teacher workspace uchun benchmark!)
- Canvas kalit: "most academics only begrudgingly use their LMS" (pcmag) → **sodda = qabul qilinadi**; "faculty achieve proficiency in 2-3 hours vs 3-6 for Moodle"
- **Canvas kamchiliklari** (arifkabir critique + g2): har kursda boshqa-boshqa homepage (standard emas); notifications yo'qolishi; design 2019'dan beri yangilanmagan; "extra tabs" (extraneous features)
- **Moodle**: 37% "legacy" deb baholaydi; "feels like 2015 interface" (checkthat) — **eski UI = foydalanuvchi rad etadi**
- **Blackboard**: legacy, 4.1/5 — past UX bozor yo'qotadi

**Edikit uchun 10 saboq (Canvas'dan):**
1. Left sidebar global navigation — hamma sahifada bir xil
2. Dashboard: kurs/test **card'lar** + "Yaqinlashayotgan" + "To Do" + "Natijalarni ko'rib chiqish"
3. **SpeedGrader pattern** — grading: rubrik + annotatsiya + inline feedback (teacher workspace)
4. **Standartlashtirilgan sahifalar** — har kurs/test bir xil struktur (Canvas xatosi — Edikitda yo'q)
5. Notification'lar aniq, yo'qolmaydi (Canvas xatosi — thefinch bilan mos)
6. Sodda, "2-3 soatda o'rganiladi" (proficiency) — Moodle'ning murakkabligi emas
7. UI tez-tez yangilanadi (Canvas "2019 design" tanqidi)
8. MasteryPaths (personalized learning paths) — AI adaptive bilan (research_ui_tech_deep)
9. Mobile native app (Canvas mobile) — Edikit: PWA/mobile-first
10. Xususiy UI: Canvas "boring but consistent" — Edikit o'z distinctiv identifikatori bilan (style.md: Evidence Mark, Signal Rail)

## 4. 2026 UMUMIY PATTERNLAR (top-saytlar va trend reportlar kesishmasi)

Manbalar: madegooddesigns, innoricsystems, itsbuzzinteractive, socialanimal, designrush, thedesignocracy, wpmanageninja, converge.ai, clay.global, uxpin.

### 4.1. Funksional minimalizm (2026 asosiy trend)
- "After years of heavy parallax, autoplaying video, scroll-jacking — designers return to interfaces that **load fast and get out of the way**" (madegooddesigns)
- Minimalizm = bo'sh emas; **"intentional simplicity"** (innoricsystems) — har element sabab bilan
- **"2026 minimalism is not 2019 minimalism"** — bo'sh + bitta paragraf = "unfinished"; restraint daromad qiladi (itsbuzzinteractive)

### 4.2. Dark mode — standart (lekin craft kerak)
- **60% eng yaxshi saytlar dark-first** (socialanimal 50 ta tahlil)
- **81.9% user'lar dark mode yoqadi** (designrush)
- **"Dark Mode 3.0"** — OLED uchun true black + vibrant aksentlar (converge.ai) — lekin **madegooddesigns qarshi**: "elevated dark greys like #121212, maintain WCAG contrast rather than slapping a dark filter"
- Muvozanat: **light va dark parallel, craft bilan** (madegooddesigns) — style.md 20 bilan mos

### 4.3. Tipografiya — hero (2026 eng katta shift)
- "Typography as hero content" (socialanimal) — custom variable fonts, kinetic lettering, **oversized headlines (10vw+)**
- **Variable fonts** — bitta fayl, weight/width dinamik (socialanimal)
- **Serif comeback** body matn uchun (socialanimal)
- Lekin: **"2-3 font max"**, legibility (multipurposethemes; gapsystudio)

### 4.4. Performance = dizayn qarori
- **53% mobil user'lar 3 soniyadan ortiq yuklanadigan saytdan ketadi** (Google 2025 — socialanimal)
- "Lighthouse score is the design" (socialanimal)
- "Core Web Vitals have made performance a design constraint" (madegooddesigns)
- Edikit: LCP<2.5s, INP<200ms, CLS<0.1 (research_ui_tech_deep 2)

### 4.5. Accessibility = craft (95.9% hali yiqilmoqda!)
- **95.9% homepage WCAG'da yiqiladi** — "most fixes are design decisions" (designrush)
- "Inclusive design by default" — Google 2026 ranking'da accessibility score (thedesignocracy)
- Edikit: WCAG 2.2 AA — raqobat ustunligi (style.md 41.3 trust bar)

### 4.6. Bento grid — layout standart (2026)
- Bento: modulli, asymmetric card bloklar — feature/hierarchy uchun (converge.ai, itsbuzzinteractive)
- Edikit: landing feature grid, teacher dashboard — bento pattern

### 4.7. Ethical UX / trust-driven
- "Ethical web design: explicit consent, transparent data, easy privacy controls, reversible actions, no dark patterns" (clay.global)
- Edikit: DSAR, consent log, privacy — allaqachon rejalangan (D-23/25); landing'da ham ko'rsatish

### 4.8. AI personalization
- "Websites shift layout/content/CTA based on user behavior" (converge.ai)
- Edikit: adaptive (research.md 8), AI co-pilot (tech 4)

### 4.9. Mikro-interaksiyalar
- **<300ms** (thedesignocracy: "Keep animations under 300ms")
- "Micro-interactions that teach" — feedback beradi (password indicator), support xatlarini kamaytiradi (-22% — designocracy)

## 6. QABUL MEZONLARI (top-sayt benchmark qo'llanganda)

1. Landing: bitta vazifa (Google tamoyili), editorial grid, institut "cinematic" ko'rinishi, restraint motion (By-Kin)
2. Auth: minimal (2-3 field), trust + warmth (Jeton/Aventura)
3. Student panel: Canvas-pattern — left sidebar + cards + "Yaqinlashayotgan" + "To Do" + progress
4. Teacher: SpeedGrader-pattern — rubrik + annotatsiya + inline feedback; density (GitHub/Amazon)
5. Motion: <300ms micro; "transitions that never call attention" (By-Kin); reduced-motion
6. Tipografiya: variable font, oversized hero (landing), 2-3 font max, legibility
7. Dark mode: craft (off-black #121212, WCAG), light parallel; **Edikit light default, dark sifatli**
8. Performance: LCP<2.5s, INP<200ms, CLS<0.1; "Lighthouse is the design"
9. A11y: WCAG 2.2 AA — 95.9% fail qiladigan joyda bu ustunlik
10. Ethical UX: no dark patterns, consent/privacy ko'rinadi
